# Azure AI Sentiment Analysis Chatbot

This project demonstrates the integration of a traditional Python chatbot
with Microsoft Azure AI Language sentiment analysis.

## Capabilities
- Basic greeting responses
- Azure AI sentiment analysis
- Positive, negative, neutral, and mixed sentiment detection
- Confidence scores
- Help/capabilities command
- Empty-input handling
- Exit command

## Installation

pip install -r requirements.txt

## Azure Configuration

Set the following environment variables before running the application:

AZURE_LANGUAGE_ENDPOINT
AZURE_LANGUAGE_KEY

Do not store Azure API keys directly in the source code.

## Run

python chatbot.py
